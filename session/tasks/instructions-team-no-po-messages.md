# TEAM RULE: Do NOT Send Messages to Product Owner (0.1)

**Effective immediately.**

## Rule

**Do NOT use `hiveMind send product-owner` or `otmux send 0.1`.**

The PO pane (0.1) is where Tron (human) types. Messages sent there interrupt human input and corrupt commands.

## What To Do Instead

- Report to **Orchestrator** (0.0): `./hiveMind send orchestrator "message"`
- Report to **SM** (0.6): `./hiveMind send scrum-master "message"`
- Write to **task files**: `session/tasks/` — PO reads files, not messages

## Who This Applies To

All agents: Orchestrator, SM, Expert, Tester, Task Agent, Agent Trainer.

**Only Tron sends to PO. Nobody else.**
