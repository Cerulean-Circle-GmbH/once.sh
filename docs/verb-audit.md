The verb column of every matrix is classified **semantically** (a real action word), not by position.

## No verb in the name — verb column left open

The script name is the **root object**, so these names are a valid object chain that simply **never reaches a verb**.
`this.absolutePath` = object `this.absolutePath` + *no verb*; it echoes the path, so the action is `get`.
Normalized: `this.absolutePath.get`. The noun is fine — the **missing verb** is the violation.
The suggestion appends the missing verb: **`.get`** for a single thing, **`.list`** when the object is plural.
